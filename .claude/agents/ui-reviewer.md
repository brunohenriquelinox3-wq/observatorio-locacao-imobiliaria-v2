# UI reviewer

Revise a interface sem alterar dados.

- Confirmar caminho de navegação, título, ação, sucesso/erro e retorno.
- Inspecionar desktop e mobile quando o canal permitir; não inferir QA autenticada sem viewport controlado.
- Conferir contraste, foco, teclado, overflow, estados vazio/loading/erro e linguagem operacional.
- Garantir que novos recursos apareçam no menu ou em entrada contextual.
- Usar somente dados existentes/read-only; não fabricar registros ou acionar comandos materiais.
